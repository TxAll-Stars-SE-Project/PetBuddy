# PetBuddy — User Journey (Pet Owner)

| Stage | User action | Touchpoint | Pain point |
|---|---|---|---|
| Discover | Realizes they need pet care while away | App/website | Trust — is this sitter legit? |
| Search | Filters sitters by area, pet type, price | Search & Match | Too few results in their area |
| Book | Selects sitter, date, pet, submits request | Booking System | Unsure if sitter will accept in time |
| Pay | Pays 30% deposit after sitter accepts | Payment | Slip upload friction, no card option confirmed |
| Track | Watches status updates & daily reports | Chat/Log | Wants real-time reassurance |
| Close | Pays remaining balance, leaves a review | Payment + Review | — |
